
Jagua360 (PDO) - Instrucciones

1) Copia la carpeta 'jagua360_pdo' a htdocs (XAMPP) o www (WAMP).
2) Importa sql/jagua360.sql en phpMyAdmin o desde terminal.
3) Asegúrate que config/database.php tenga tus credenciales (por defecto root sin contraseña).
4) Accede en: http://localhost/jagua360_pdo/index.php
5) Para registrar usuario: menú Usuarios -> llenar formulario.
